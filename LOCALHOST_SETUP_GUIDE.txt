═══════════════════════════════════════════════════════════════
  STEP 1: PREREQUISITES (Install these first)
═══════════════════════════════════════════════════════════════

  ✦ Node.js 18+    → https://nodejs.org (download LTS version)
  ✦ MongoDB        → ONE of these options:
    
    OPTION A: MongoDB Local (recommended for offline dev)
      → Download Community Server: https://www.mongodb.com/try/download/community
      → Install and run as service (starts automatically)
      → Default connection: mongodb://localhost:27017
    
    OPTION B: MongoDB Atlas FREE (no local install needed, needs internet)
      → Go to https://cloud.mongodb.com → Create free cluster
      → Database Access → Add user (remember password)
      → Network Access → Add IP → Allow 0.0.0.0/0 (allow all)
      → Connect → Drivers → Copy connection string
      → Looks like: mongodb+srv://user:pass@cluster0.xxxxx.mongodb.net/
    
    OPTION C: MongoDB via Docker (if you have Docker)
      → docker run -d -p 27017:27017 --name mongo mongo:7


═══════════════════════════════════════════════════════════════
  STEP 2: CONFIGURE THE BACKEND
═══════════════════════════════════════════════════════════════

  1. Open file:  backend/.env

  2. UPDATE THESE 2 FIELDS (minimum required):

     ┌──────────────────────────────────────────────────────┐
     │  MONGODB_URI=mongodb://localhost:27017/azolve_db    │  ← If using local MongoDB
     │  OR                                                 │
     │  MONGODB_URI=mongodb+srv://USER:PASS@CLUSTER/azolve│  ← If using Atlas
     │                                                      │
     │  JWT_SECRET=any-random-string-min-32-chars          │  ← Change this!
     └──────────────────────────────────────────────────────┘

  3. OPTIONAL FIELDS (only needed if you want email/password reset):
     - EMAIL_HOST / EMAIL_USER / EMAIL_PASS (Brevo or Gmail App Password)
     - BREVO_API_KEY (alternative to SMTP, works on any network)

  4. Cashfree is set to SANDBOX mode by default for localhost
     (no real charges — safe to test). To test with your live
     credentials, change: CASHFREE_ENV=production

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

  ❌ "MongooseError: connect ECONNREFUSED"
     → MongoDB is not running. Start it first:
       Windows:  Open "MongoDB Compass" or start service
       Mac:      brew services start mongodb-community
       Linux:    sudo systemctl start mongod
     → Or switch to MongoDB Atlas (cloud) in .env

  ❌ "Port 3000 already in use"
     → Kill the process:  lsof -i :3000  then kill PID
     → Or change PORT=3001 in .env

  ❌ "Cashfree credentials not configured"
     → Make sure CASHFREE_APP_ID and CASHFREE_SECRET are set in .env
     → Restart the server after changing .env

  ❌ "401 Unauthorized" on API calls
     → Login first at /login.html to get a token
     → Token is stored in localStorage as 'azolve_token' or 'authToken'

  ❌ Office editors show "Sign in to save"
     → You need to login first for auto-save to work
     → Without login, you can still edit locally (won't persist)

  ❌ Images/assets not loading
     → Make sure you're accessing via http://localhost:3000
       (NOT opening HTML files directly from file system)

  ❌ npm install fails
     → Delete node_modules and package-lock.json, then:
       npm cache clean --force && npm install


═══════════════════════════════════════════════════════════════
  DEVELOPMENT TIPS
═══════════════════════════════════════════════════════════════

  • Use "npm run dev" for auto-restart on backend code changes
  • Frontend files (HTML/CSS/JS) update on browser refresh —
    no restart needed since Express serves them as static files
  • MongoDB data persists in the database between restarts
  • To reset all data: delete the database or change DB name in
    MONGODB_URI (e.g., azolve_db → azolve_dev)
  • To seed sample data:  npm run seed
  • Socket.IO works on localhost for real-time chat & meetings
